# 密碼本 Password Vault

一個在本機執行的個人密碼管理工具。所有資料經主密碼加密後儲存於本機，不連網、不上雲端。

主要提供兩項功能：

- **帳密記錄器**：集中保管各服務的帳號與密碼，可分類、搜尋、一鍵複製。
- **密碼生成器**：產生指定長度與字元組成的隨機強密碼。

---

## 安全性

開啟程式時需輸入**主密碼**才能解鎖資料。

- 資料以 **Argon2id** 由主密碼推導金鑰，再以 **Fernet（AES）** 加密，儲存為 `vault.dat`。
- 在未輸入正確主密碼的情況下，`vault.dat` 無法被還原，內容為無法閱讀的密文。
- **主密碼無法找回**。金鑰由主密碼推導而來，一旦遺忘主密碼，已加密的資料將無法復原，請務必妥善保管。

## 基礎架構

```
password-vault/
├─ main.py                  # 程式進入點
├─ pwvault/
│  ├─ crypto_utils.py       # Argon2id 金鑰推導與 Fernet 加解密
│  ├─ vault.py              # 資料的讀寫與加密儲存
│  ├─ password_generator.py # 密碼生成邏輯（使用 secrets）
│  └─ ui/
│     ├─ unlock_dialog.py   # 啟動時的主密碼輸入視窗
│     ├─ main_window.py     # 主視窗：帳密記錄器
│     └─ generator_dialog.py# 密碼生成器
├─ tests/                   # pytest 測試
├─ requirements.txt         # 相依套件
└─ dist/PasswordVault.exe   # 打包好的執行檔
```

- **介面框架**：PySide6（Qt for Python）
- **加密**：argon2-cffi（金鑰推導）＋ cryptography 的 Fernet（加解密）
- **隨機來源**：Python 內建 `secrets` 模組
- **執行環境**：Python 3.12 / Windows

## 使用方式

### 方式一：直接執行（不需安裝 Python）

1. 下載 `dist/PasswordVault.exe`。
2. 雙擊執行，第一次開啟時設定主密碼。
3. 之後每次開啟，輸入主密碼即可解鎖。

> **關於防毒誤判**：本執行檔以 PyInstaller 打包，Windows Defender 或部分防毒軟體可能將其誤判為可疑程式並攔截。這是 PyInstaller 打包檔的常見現象，並非實際威脅。若被攔截，可在防毒軟體中將其標示為信任後再執行。

### 方式二：從原始碼執行

需先安裝 Python 3.12。

```bash
pip install -r requirements.txt
python main.py
```

## 操作說明

### 帳密記錄器（「新增帳密」分頁）

- **左側**：搜尋列（依名稱或帳號搜尋，不分大小寫）、標籤篩選（可多選）、帳密列表。
- **右側**：編輯區，欄位包含名稱（必填）、帳號、密碼、標籤（以逗號分隔）。
- **帳號**與**密碼**各有「複製」按鈕，可直接複製到剪貼簿；密碼預設隱藏，按「顯示」才會顯示明文。
- 填寫後按「儲存」新增或更新；選取列表中的紀錄後按「刪除」可移除。

### 密碼生成器（「密碼生成器」分頁）

- 可設定密碼總長度，以及大寫字母、小寫字母、數字、符號各自的最少數量。
- 產生的密碼可直接複製使用。
